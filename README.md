# 墨清｜試卷黑白增強

專為太淡、帶灰底的考古題設計的 PDF 列印調整工具。以 PDF.js 在瀏覽器渲染，以 pdf-lib 產生新 PDF；檔案不傳送到後端。網站程式碼公開，但使用者選擇的文件不會提交到 GitHub。

## 功能
- 拖曳或選擇 PDF，逐頁比較原稿與結果
- 一般試卷、淡字加深、圖片保留灰階三種預設
- 純黑白閾值、灰階加深、灰底去除、筆畫微加粗
- 200 / 300 / 400 DPI 匯出，預設 300 DPI
- 保留原始頁面尺寸與方向，全頁套用相同設定
- 進度與取消、損壞及加密 PDF 提示、手機排版

## 使用
1. 從考試網站下載考古題 PDF。
2. 開啟網站，選擇 PDF。一般文字試卷用純黑白，有圖表則用增強灰階。
3. 調整黑白判定，逐頁確認細字、標點、圖表沒有遺失。
4. 下載增強 PDF，先試印一頁；建議實際大小列印。

## 限制及隱私
- 不能重建原始檔已遺失或失焦的細節，不是 AI 超解析或 OCR。
- 輸出是影像型 PDF，不保留可搜尋文字、連結、書籤或表單。
- 原稿不變；輸出大小可能增加。大型文件耗用記憶體，建議拆分；單檔上限 100 MB，單頁渲染上限 4000 萬像素。
- 密碼文件需先在其他 PDF 閱讀器解除保護。本工具不詢問密碼。
- 文件只在本機記憶體處理，重新整理即清除；網頁資源由 GitHub Pages 提供，字型可能向 Google Fonts 請求（不含 PDF 內容）。
- 列印效果仍取決於原稿及印表機，過高閾值可能引入雜點，去灰底可能移除淡色細節，加粗可能讓小字黏合。

## 開發
```sh
npm ci
npm run dev
npm test
node tests/browser.mjs
npm run build
```
瀏覽器端到端測試使用本機 Microsoft Edge（Playwright），自動建立兩頁淡字 PDF，驗證載入、二值化、切頁、模式切換、下載、頁數與尺寸、行動版不溢出及損壞檔案錯誤提示。`TEST_URL` 可指定正式網址測試。測試檔為人工產生的測試資料，不是使用者原稿。

GitHub Actions 每次推送 main 自動測試、建置及部署 Pages，無需 API key。設定 Pages 來源為 GitHub Actions。
